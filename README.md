# Kobald — AIF Portfolio

SACE Stage 2 Activating Identities and Futures (AIF) portfolio by Cameron Lonnie.

## What this portfolio is about

Kobald is my evolving AI project. It began as **Project JARVIS**, a home-server idea inspired by the helpful-but-not-uncontrolled AI in *Iron Man*. It has become a governed AI system for research and authorised security work. Its rule is simple: **autonomous in thought, cautious in action**.

My learning goal is not just to make an impressive AI output. It is to learn how a system becomes trustworthy: through approval gates, testing, evidence handling, audit trails, honest documentation, and changing course when evidence shows a weakness.

This repository is the portfolio evidence. It deliberately separates what is independently verifiable from my working notes and claims that still need a new capture. That matters because an honest limitation is better evidence of learning than an uncheckable claim.

## Evidence status key

| Label | Meaning |
|---|---|
| **Verified capture** | Directly supported by a dated commit, email record, supplied document, or saved extract in this repository. |
| **Reported working-copy evidence** | I observed it in my local project, but a current public capture has not yet been added. |
| **To verify** | A useful lead or self-report that I must not present as proven until I capture it. |

Links in this repository are navigation, not the evidence by themselves. The assessment advice says live links are not accepted as evidence, so the portfolio contains dated written captures and identifies where a screenshot, exported email, or new code capture still needs to be attached.

## Privacy and academic integrity

Private email addresses, phone numbers, home-network details, private server paths, and credentials have been removed. Community contacts are identified only when that is necessary to explain the evidence. Technical claims are qualified to match their evidence status.

The project source is at [CL-BAF/Kobald](https://github.com/CL-BAF/Kobald). This portfolio is about my process, decisions and learning; it is not a claim that Kobald is production-ready or independently certified safe.
